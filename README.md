# Kimo

تطبيق مراسلة فورية بتصميم أسود. يتكوّن من خادم (Node.js) وواجهة ويب تعمل على الهاتف ويمكن تثبيتها كتطبيق.

## ما الذي يعمل الآن؟
- إنشاء حساب وتسجيل الدخول (اسم مستخدم + كلمة مرور)
- البحث عن شخص بالاسم وبدء محادثة
- رسائل فورية بين شخصين، مع علامات الإرسال والتسليم والقراءة
- "متصل / غير متصل" و"يكتب الآن…"
- مشاركة رابط التطبيق، وتثبيته على الشاشة الرئيسية

## ما الذي لم يُبنَ بعد؟
المكالمات، الحالات، الصور والملفات، الرسائل الصوتية، المجموعات، التحقق برقم الهاتف.

---

## الخطوة 1: ارفع المشروع إلى GitHub
1. أنشئ حسابًا على github.com ثم مستودعًا جديدًا (New repository) باسم `kimo`.
2. ارفع محتويات هذا المجلد كما هي (Add file ← Upload files). لا ترفع مجلد `node_modules` إن وُجد.

## الخطوة 2: شغّل الخادم على Render (خطة مجانية)
1. أنشئ حسابًا على render.com وسجّل الدخول بحساب GitHub.
2. اختر New ← Web Service ← اختر مستودع `kimo`.
3. الإعدادات:
   - Runtime: `Node`
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: `Free`
4. اضغط Create Web Service وانتظر دقائق. سيظهر لك رابط مثل `https://kimo-xxxx.onrender.com`.

## الخطوة 3: افتحه على هاتفك وشاركه
- افتح الرابط في المتصفح، أنشئ حسابًا، وجرّب.
- **المشاركة:** أرسل الرابط لأي شخص. كل شخص ينشئ حسابه ثم يبحث عن اسم مستخدمك.
- **التثبيت على أندرويد:** Chrome ← القائمة ⋮ ← "تثبيت التطبيق" (أو من قائمة Kimo داخل التطبيق).
- **التثبيت على آيفون:** افتح الرابط في Safari ← زر المشاركة ← "إضافة إلى الشاشة الرئيسية".

---

## تنبيهات مهمة (على الخطة المجانية)
1. **الخادم ينام** بعد فترة من عدم الاستخدام، وأول فتح بعدها قد يستغرق حوالي دقيقة.
2. **البيانات تُحفظ في ملف على القرص المؤقت**، وقد تُمسح عند إعادة التشغيل أو التحديث. هذا مناسب للتجربة فقط. للاستخدام الحقيقي نحتاج قاعدة بيانات دائمة (الخطوة التالية).
3. أي شخص يعرف الرابط يستطيع إنشاء حساب، ويمكن البحث عن المستخدمين بالاسم.
4. الرسائل غير مشفّرة من طرف إلى طرف حاليًا.

## التشغيل على جهازك (اختياري)
```
npm install
npm start
```
ثم افتح http://localhost:3000
